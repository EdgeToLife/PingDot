# PingDot

[English version](README.md)

Кружок в строке меню macOS, который показывает состояние интернета. Каждые 2 секунды приложение пингует 8.8.8.8 и 1.1.1.1 — обычным ICMP, без sudo.

| Кружок | Что значит |
|:--:|---|
| 🟢 | всё хорошо |
| 🟡 | связь нестабильна: за последние ~30 с потери ≥ 10%, медиана пинга ≥ 150 мс или джиттер ≥ 50 мс — либо не дошёл последний пинг |
| 🔴 | ни один узел не ответил 3 раза подряд, или Mac вообще не подключён к сети |
| ⚪ | данных ещё нет: первые секунды после запуска, смены сети или выхода из сна |

Как считается: потери — суммарно по всем отвечающим узлам (это потери на твоём канале), пинг и джиттер — по лучшему узлу. Если какой-то сервер не отвечает совсем (например, заблокирован), он просто не учитывается.

При обрыве кружок желтеет через 1,5–3,5 с и краснеет через 5,5–7,5 с. После восстановления ещё ~25 с горит жёлтым — пока потери не уйдут из окна статистики.

По клику — меню: общий статус, по каждому узлу последний пинг, медиана, джиттер и потери, плюс переключатели «Показывать пинг в строке меню» (ширина фиксированная — соседние значки не прыгают) и «Запускать при входе в систему».

Нужна macOS 13 или новее. Сборка универсальная (Apple Silicon + Intel).

## Установка

1. Скачай `PingDot.zip` из [Releases](../../releases/latest), распакуй и перетащи `PingDot.app` в «Программы».
2. Приложение подписано самодельной подписью, а не через Apple, поэтому первый запуск macOS заблокирует. Разреши один раз:
   - **macOS 15 и новее:** попробуй открыть и закрой предупреждение, затем «Системные настройки» → «Конфиденциальность и безопасность» → **«Всё равно открыть»**.
   - **macOS 13–14:** правый клик по приложению → «Открыть» → «Открыть».
   - **Любая версия, через Терминал:** `xattr -dr com.apple.quarantine /Applications/PingDot.app`

## Сборка из исходников

Нужен только Swift из Command Line Tools (полный Xcode не обязателен):

```sh
xcode-select --install      # если ещё не установлены
./build.sh                  # → build/PingDot.app
./build.sh install          # собрать, положить в /Applications и запустить
ARCHS=arm64 ./build.sh      # только Apple Silicon (по умолчанию — универсальная)
```

Проверка пинга из терминала — три пинга на каждый узел:

```sh
build/PingDot.app/Contents/MacOS/PingDot --check
```

## Настройка

Всё в [`Sources/Config.swift`](Sources/Config.swift): узлы, период опроса, таймаут, размер окна, пороги жёлтого и красного. Поменял — `./build.sh install`.

## Что где

- [`Pinger.swift`](Sources/Pinger.swift) — ICMP Echo через сокет `SOCK_DGRAM` + `IPPROTO_ICMP` (macOS разрешает его без root): сборка пакета, контрольная сумма, отбор своих ответов, замер времени.
- [`Monitor.swift`](Sources/Monitor.swift) — опрос раз в 2 с, статистика за окно, логика цвета; сброс при смене сети (`NWPathMonitor`) и после сна.
- [`StatusBarController.swift`](Sources/StatusBarController.swift) — кружок, меню, автозапуск (`SMAppService`).
- [`App.swift`](Sources/App.swift) — точка входа и режим `--check`.

## Выпуск новой версии

GitHub Actions собирает приложение при каждом пуше. Чтобы выпустить релиз, запушь тег с версией:

```sh
git tag v1.1
git push origin v1.1
```

Сборка возьмёт номер версии из тега и приложит `PingDot.zip` к новому релизу.

## Если что-то не так

- **Кружка не видно** — на MacBook с «чёлкой» значки, которым не хватило места, прячутся за ней. Перетащи PingDot правее, ближе к часам, удерживая ⌘.
- **Автозапуск перестал работать после пересборки** — сними и снова поставь галочку «Запускать при входе в систему».
- **Красный при живом интернете** — значит, в этой сети режут ICMP (бывает в офисных и гостевых сетях). Тогда нужна проверка по TCP вместо пинга.
